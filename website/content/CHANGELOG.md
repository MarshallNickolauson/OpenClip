# Changelog

## 0.2.0: native rewrite

- **Native rewrite in egui.** OpenClip is now a single native Rust app with no web view.
- **Renamed from ClipCraft to OpenClip.**
- **OS-licensed encoders only.** Export uses AVFoundation and VideoToolbox; there is no ffmpeg and no openh264.
- **Faster UI.**

## 0.1.0

- **First release as ClipCraft.** Import, whisper.cpp transcription, Vision faces, local scoring, MCP server, 9:16 preview, face-following camera, captions, timeline, batch export, jump cuts and unsaved-changes tracking.
