Privacy Policy

Last updated: 16 October 2026

Short version: we collect no personal data, we set no cookies, and the app has no telemetry. Your videos, transcripts and clips stay on your Mac. The site only remembers your theme choice, in your own browser.

The app

OpenClip is a native macOS application that runs entirely on your device. It has no accounts, no telemetry, no crash reporting and no cloud features. Videos, transcripts, face data, edits and exports stay on your computer. Transcription, face detection, clip scoring, captions and encoding all happen locally. The app makes two kinds of network request, both optional: a download of a speech-recognition model (see below) and a check of GitHub for a newer release.

Claude and the local MCP server

OpenClip ships a local MCP server, openclip-mcp. It is started on your Mac by Claude Desktop or Claude Code over standard input and output, and nothing is hosted by us. If you ask Claude to find clips, the assistant you chose receives the clip candidates and any transcript text it requests, and sends them to that service. That is your choice and is governed by that service's terms and privacy policy. OpenClip itself sends nothing. If you never connect an assistant, the built-in Quick pick scores moments entirely on your Mac.

This website

This website is hosted on Cloudflare Pages. Cloudflare processes ordinary server logs (such as IP addresses) to deliver and secure the site, as described in the Cloudflare Privacy Policy. We do not add analytics, advertising, social-media trackers or embedded third-party widgets, and the site loads no external fonts or scripts. If you pick a theme, that choice is saved in your browser's local storage on your device only (see the cookie policy).

GitHub star count

The star count in the header is fetched by our own server from GitHub's public API and cached for an hour. Your browser only talks to this site; GitHub never sees your IP address from that request.

Downloads

The installer is served from GitHub. GitHub may process your IP address when you download; see the GitHub Privacy Statement.

Update check

The app can ask GitHub whether a newer release exists. It never downloads or installs anything by itself.

Optional model download

The first time you transcribe a video, the app downloads a Whisper model file from Hugging Face. That request is made directly from your device to Hugging Face, whose privacy policy applies. No audio or project data is sent.

Your rights

Because we hold no personal data about you, there is nothing to access, correct or delete. If you contact us (for example by opening a GitHub issue), the content you submit is handled by GitHub under its terms.

Children

The site and app are not directed at children and we do not knowingly collect any personal information.

Changes

If this policy changes, the date above will be updated and the change recorded in the public repository history.
