Download OpenClip

A free, open-source macOS app that turns long talks into vertical clips. No account, no watermark, no subscription. Version %VERSION%.

macOS

macOS 13 or later · Apple silicon tested · .dmg
Download %DMG%
  1. Open %DMG% and drag OpenClip to Applications.
  2. The app is ad-hoc signed and not notarised. The first time, right-click OpenClip and choose Open, then confirm. (Or run xattr -dr com.apple.quarantine /Applications/OpenClip.app in Terminal.)
  3. Drop a video in. The speech model downloads once, the first time you ask for a transcript.

Prefer one command? It downloads the disk image with curl, copies the app to Applications and opens it:

curl -fsSL %HOST%/install.sh | bash
Early alpha. OpenClip is macOS only for now and has had limited testing. Please report problems on GitHub.
Prefer to build it yourself? OpenClip is MIT licensed. See the getting started guide or the source on GitHub.
