Roadmap

What we plan to build next. Nothing here is a promise or a date; it is the list we are working through, roughly in order. Follow progress in the changelog or on GitHub.

Next

  • Notarised builds. Distribution Sign and notarise the app so macOS stops asking you to right-click Open on first launch.
  • Active-speaker detection. Framing Follow whoever is talking in scenes with several people, instead of the closest, left or right face.
  • More MCP tools. Claude Revise a clip by instruction, for example "start a sentence later" or "make it shorter".

Captions

  • More caption styles and fonts beyond Pop, Boxed and Clean.

Export

  • Parallel batch and queue exports so several clips render at once.

App

  • Update check with an in-app highlight when a newer version is available.

Platforms

  • Windows port. Platform OpenClip is macOS only today because it relies on the Mac's own codecs and Vision framework. A Windows version would need a different path for each.

Missing something you need? Open an issue and tell us.
